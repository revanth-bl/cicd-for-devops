# 🚀 CI/CD for DevOps

Welcome to my **CI/CD for DevOps** learning repository.

This repository documents my hands-on journey to mastering **Continuous Integration (CI)** and **Continuous Deployment (CI/CD)** using industry-standard DevOps tools and practices. Instead of only learning the theory, I build real CI/CD pipelines, automate workflows, and gain practical experience with Jenkins, GitHub, Docker, and deployment automation.

---

# 🎯 Goal

* Understand CI/CD fundamentals
* Learn Jenkins from beginner to advanced
* Build automated CI/CD pipelines
* Integrate GitHub with Jenkins
* Automate application build, testing, and deployment
* Prepare for Kubernetes, Terraform, AWS, and production DevOps workflows

---
